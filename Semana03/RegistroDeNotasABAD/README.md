# Registro de Notas ABAD - Semana 3

Aplicación móvil desarrollada en Jetpack Compose para la asignación y cálculo de promedios ponderados de notas de programación.

## Características y Controles Utilizados

- **Slider:** Utilizados para la selección interactiva de notas de 0 a 20 con pasos enteros (`valueRange = 0f..20f`, `steps = 19`).
- **Switch:** Control para habilitar o deshabilitar el redondeo automático del promedio final.
- **Checkbox:** Control de confirmación que habilita dinámicamente el botón de cálculo.
- **Botón Limpiar:** Restablece todos los controles y estados a su valor por defecto.
- **Tarjeta de Resultados:** Muestra el promedio ponderado, promedio final y un chip de observación con color dinámico según la escala institucional.
