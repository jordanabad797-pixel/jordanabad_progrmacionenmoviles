# Prompt usado para el desarrollo con IA

Actua como experto en el curso de Programacion en Moviles, con manejo de
Kotlin, Android Studio y Git/GitHub. Te paso el PDF de mi laboratorio (Lab02:
Carrito de compras en Kotlin), donde se pide programar un carrito de compras
por consola usando variables, data class, funciones y estructuras de decision.
Ya lo desarrolle siguiendo la guia tal cual, sin IA, en una rama llamada
sin-ia.

Ahora mi profesor pide una segunda version del mismo programa, en una rama
aparte llamada con-ia, con estas condiciones:

- Debe estar orientada a objetos: clases con sus propios metodos, no data
  class con funciones sueltas como en la version base
- Debe tener abstraccion: al menos una clase abstracta con un metodo que las
  clases hijas implementen de forma distinta (por ejemplo, para calcular el
  IGV y el descuento por separado)
- El resultado final en consola debe ser el mismo que el de la guia: nombre
  del cliente, productos agregados, detalle con columnas alineadas y 2
  decimales, subtotal, IGV (18%), total, producto mas caro y descuento
  aplicado segun el monto total
- Necesito el codigo entregado por partes, cada parte lista para hacer un
  commit distinto con su mensaje, porque el profesor exige minimo 4 commits
  por rama (8 en total)
- Mi nivel en GitHub y Android Studio es basico, casi nulo, asi que necesito
  que me expliques paso a paso donde hacer clic, y que me ayudes a resolver
  cualquier error que me salga en el camino (por ejemplo, problemas al
  ejecutar un main() dentro de un proyecto de Android)
